## 0. 四大分歧點裁定(全規格的骨架)

競品在四個根本問題上分成兩派;Weyver 的選擇決定 R1 是否守得住「讓 Ragic 客戶遷移」承諾:

| # | 分歧 | Ragic 派 | Airtable/Teable/Baserow 派 | **Weyver 裁定** |
|---|---|---|---|---|
| D1 | 表單版面模型 | **2D 格線畫布 = 填單畫面本身**(欄位任意擺位/合併/靜態文字/分段;直譯紙本單據)doc/21 | 網格優先,版面是事後投影(單欄堆疊 record detail / form view) | **2D 畫布派(must)** — 客戶生產表單就是 2D 格線+多色敘述+分段(design_chang.png);線性清單/單欄堆疊 = 遷移時版面資訊直接丟失,會被感知為降級 |
| D2 | 清單/視圖模型 | sheet 內建唯一列表頁(設計層)+ 儲存篩選(個人/共通/固定)doc/38、19 | table 之上 N 個 named views(filter+sort+group+欄位全套組態)| **混合:「Ragic 語意、Airtable 骨架」** — 底層採 `view_def`(Airtable 骨架,Baserow registry 已證架構成本低);表層每表恆有**預設檢視 = Ragic 列表頁**(設計者控,遷移零學習),使用者在其上「另存檢視」;Ragic 共通/固定篩選 = view 的治理屬性軸 `scope × locked × default × forcedFilter` |
| D3 | 工作區 IA | **首頁 = 業務分類目錄**(頁籤×每類密集表單連結 + 工作項目/行事曆 widget)實照、doc/119、90 | workspace > base > table 容器切換 | **Ragic 派** — 遷移客戶心智=單一資料庫+分類頁籤,不引入 workspace/base 兩層(對齊 docs/24「非每系統一個 tab」);**復用權限軸已建的 `form_categories` 升格為 IA 主軸** |
| D4 | 隱藏欄語意 | 設計層隱藏 ≠ 權限(Ragic 明文區分)doc/6 | Airtable shared view 隱藏欄可被設定洩出(顯示級) | **權限優先** — 檢視/版面層的隱藏一律疊在欄位級權限之上,不得成為洩漏面(AGENTS BOLA 鐵則;P0-4a maskRead 已是後端強制) |

## 1. 表單設計器(D1 落地;對應 docs/25 B「表單設計器」6 人月)

**Ragic 設計模式本質**:畫布=最終填單畫面,Excel 式 2D 格線(新表 105×21,自動擴充 doc-kb/306);左側三頁籤面板(新增元件/欄位設定/表單設定)。**全部版面能力都是 layout metadata(座標/樣式/分段/條件),與資料層正交** —— form-engine-core 的 DDL/DML 鏈不需動,主戰場 = `form_def` 增 layout schema + 設計器前端改畫布。

| 級 | 能力 | 規格要點 | 來源 |
|---|---|---|---|
| **P0** | 2D 格線畫布 | 欄位 row/col/span 擺位、拖曳移動、跨欄合併;列高/欄寬可調。存 layout metadata,不動 PG schema | doc/21、53 |
| **P0** | 靜態敘述元素 | 敘述欄位(字型/大小/顏色/超連結/Markdown/「僅設計模式可見」)+ 插入圖片(logo) | doc/35、123 |
| **P0** | 表單分段(section tabs) | 右鍵指定列成段、可命名/樣式;子表格可入段(lazy load 加速) | doc/121 |
| **P0** | 欄位設定核心 | 預設值(17 種變數 `$DATE/$USERNAME/$SEQ…` + 可掛公式)、唯讀、隱藏、欄位使用說明(?圖示)、placeholder | doc/50、53 |
| **P0** | **設計草稿模型** | 「不儲存不生效」= 設計 session 累積變更、批次 apply + **Ctrl+Z 復原**(架構決策:對 Weyver DDL 引擎 = 變更集缓存 → 單次 provision) | doc/143、72;Baserow undo-redo-guide |
| P1 | 條件式格式 | 顯示/隱藏/唯讀/必填/變色/訊息;日期區間/當前使用者條件;規則註解+停用開關。**排版層隱藏≠權限**(D4) | doc/6 |
| P1 | 欄位格式 mask + 驗證 | 數字 `#,##0.00`、日期含**民國年**(台灣剛需)、電話;輸入檢查 regex | doc/51、24 |
| P1 | 設計期工具 | Ctrl+K 欄位搜尋(回報座標+定位)、設計版本紀錄+還原、欄位樣式/框線 | doc/167、72 |
| P2 | 長尾 | 多版本表單(→R1 以「檢視+欄位權限」對映,見 §3)、列印頁首頁尾/換頁、凍結、複製表單架構 | doc/13、149、107、142 |

Airtable 可借鑑的**不是版面模型**,是管理性 UI:欄位清單側欄 + find a field + 群組摺疊(AT interface-layout-record-detail)。

## 2. 欄位型別全譜(對應 docs/25 B「欄位型別系統」8 人月)

現況 19 型(~15 功能)。四家 inventory 對照後分三類:

**共識型(table stakes,四家皆有,Weyver 缺 = 必補)**:系統欄 4 型(created/updated by/at;Airtable/Teable 為獨立唯讀欄型,Ragic 用預設值變數)、lookup、rollup(count/sum/max/min/avg 即達 Ragic「統計欄位」parity)、選項顏色+排序、附件多檔縮圖、rich/長文格式化。

**Ragic 獨有(R1 遷移必備側)**:連動選項(選項依另一欄過濾 doc/20)、編號/號碼格式遮罩(ISBN/身分證/車牌 doc/51)、文字遮罩(前後 N 碼)、地址(Google Maps+GPS 定位)、循環日期、匯率、**簽名**、**條碼生成**(值→Code128/QR 圖;注意與 Airtable 語意相反——AT 是相機掃碼**輸入**)、動作條碼、傳閱、選擇群組、打卡、民國年、付款(綠界)。

**Airtable 獨有(加分)**:Duration、Button(→綁 automation,R2)、AI field、Count 獨立型。

| 級 | 補齊項 | 實作要點 | 來源 |
|---|---|---|---|
| **P0** | 系統欄 4 型 | 由引擎既有 audit 欄**投影**,零新儲存;匯入時對映 Ragic 預設值變數 | doc/50;AT-OV;TB-F |
| **P0** | lookup + rollup | metadata `{linkFieldId, targetFieldId, fn}`;rollup 5 函數;N+1 dataloader(AGENTS 鐵則) | doc/27;AT;TB |
| **P0** | link 補完(現 stub) | Ragic 語意=以獨特值欄為 key 的值連結 + 連結與載入批次帶欄;來源型別白名單 | doc/27 |
| **P0** | autoNumber pattern | `前綴+{date,fmt}+{seq,padding}` + **依參照欄各自跳號** + 序號重設;每 (field, groupKey) 一序列 + advisory lock | doc/25 |
| **P0** | 選項顏色 + 連動選項 | options schema 加 `color`;連動=選項加 `parentOptionId` | doc/20、27 |
| **P0** | 圖片欄(獨立於附件)、簽名(canvas→PNG 附件管線)、條碼生成(渲染層 OSS lib,零 DB 變更)、編號格式遮罩(text+displayMask) | 各項小;客戶表單大量使用 | doc/27、51 |
| P1 | rich text(sanitized HTML/ProseMirror)、Markdown、日期進階(民國年/預設今天/時區策略)、使用者欄補完(多選+群組)、地址、循環日期、文字遮罩 | | doc/27、51;AT-DATE |
| P2 | Duration、Button、行動掃碼輸入、匯率(外部 API+circuit breaker)、傳閱/群組/打卡、付款(R2)、AI 欄(docs/17) | | |

## 3. 視圖系統與清單(D2 落地;對應 docs/25 F「列表視圖」4+1 人月;吸收 record-workbench-ui A1)

**架構落點**:`view_def(id, form_id, type, scope, locked, is_default, config JSONB{fields, filterTree, sorts, groups, freeze, pageSize})` 入 metadata catalog;filterTree 編譯走 form-engine-core 既有白名單 filter 鏈;operator registry 按欄型別宣告相容(Baserow `ViewFilterType` 範式)。**檢視隱藏欄疊在欄位權限之上(D4)。**

| 級 | 能力 | 規格要點 | 來源 |
|---|---|---|---|
| **P0** | 欄位選擇器 | per-view 顯示欄+順序;**預設檢視由設計者定 = Ragic 列表頁**(遷移零學習) | doc/38 |
| **P0** | 篩選 | 欄型別感知 operator(選項=facet 多選勾、數字/日期=範圍+快速區間、空值)+ AND/OR 一層;UI = **左側 facet rail**(Ragic 心智;rail 欄位可自訂) | doc-user/15、doc/85;TB toolbar |
| **P0** | 排序 | 標頭快速排序 + 多鍵(標頭顯示次序數字) | doc-user/16 |
| **P0** | 儲存檢視三態 | 個人 / 共通(群組限定+可設預設)/ 固定(admin 強制不可移除)—— Ragic 客戶重度依賴;= `scope×locked×default×forcedFilter` 屬性軸 | doc/19 |
| **P0** | 快速搜尋、分頁、批次基本 | 表內關鍵字(先 ILIKE);預設 25/頁可調;勾選+刪除+匯出 CSV/Excel | doc-user/17、1、47 |
| P1 | 標頭**加總與分析**/summary bar、分組+群組小計(≤3 層;Ragic 缺 = 向上差異化)、凍結欄、星號、右鍵以值篩選、大量修改(**明確定義公式重算語意** —— Ragic 不重算是坑)、Kanban/Calendar 檢視(取代 Ragic 報表位)、檢視分享連結 | | doc-user/19、5;AT group;doc/107、97、67 |
| P2 | row coloring、row height、檢視分區/最愛、個人模式 overlay + Exit-and-sync(Teable 特色)、gallery/timeline、URL 篩選參數、>1000 筆 preview 策略 | | AT;TB toolbar |

## 4. 工作區 IA + 記錄頁(D3 落地;對應 docs/25 §0.4 補列「分類導覽目錄」+ record-workbench A0)

| **P0** | 全文檢索 + 通知鈴鐺 | 兩 scope(全庫/表內)、`欄位:值` 語法;通知中心殼(通道接 P0-4b) | doc-user/17、12 |
| **P0** | 記錄頁標準動作列 | 複製這筆/刪除/友善列印/PDF/Excel/Email 寄出 | doc/100、4 |

| P1 | **自訂按鈕 7 類**(資料拋轉/更新本表/更新他表/Email/SMS/合併按鈕/URL;+執行前確認/簽核 gate/群組權限;可入列表欄)、簽核框(階層/會簽擇辦/金額條件/簽核完自動執行按鈕)、留言+@提及+儲存格註解、合併列印(Excel/Word 範本) | 按鈕與簽核 = workflow 模組(P0-4 系)的 UX 面 | doc/68、62、69、95、15、169、42 |

## 5. 與既有規劃對齊

- **docs/25**:本規格是 §0.4 稽核的「怎麼做」;B/F 條目人月不變(6/8/4+1 等既列),僅定案作法。§0.4 補列之 分類目錄(2)/ 標籤 QR(2)人月待併 docs/04。

- **多版本表單**:R1 不做獨立機制,以「檢視 + 欄位級權限」對映(§0 D2、§1 P2)。
