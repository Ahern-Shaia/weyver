# Weyver 完整產品功能表(v2.7)

> **產品定位(2026-07-17 架構主張定案)**|**以 Ragic 表單引擎為基底,取代 ERP,融合 MES + ISO 的一站式企業平台**(Cloud SaaS + On-premise Edge Gateway hybrid;統一 TypeScript 全棧;全 OSS;不 fork Odoo)。**廠商放棄原有 ERP(鼎新 / 千奧 / 正航等),全面改用 Ragic 範式取代 ERP**,並在同一基底上開展 MES + ISO 功能。
> **關鍵架構主張**|**表單引擎是 substrate(平台底層),不是 21 模組之一** —— 採購單 / 銷貨單 / 工單 / BOM / 品檢記錄 / ISO 文件 皆為引擎上的「表單 app」(動態 schema + 子表 + 公式 + 關聯 + 工作流 + 權限)。純表單吃下約 80%(主檔 / 單據 / 簽核 / 基本報表 / 品檢 / 文管);**深層計算邏輯(GL 複式過帳 + 期結、MRP 展開、成本結轉、庫存估值、合併報表)由引擎之上的「計算層」補齊** —— 那是「算」不是「填」。故真實架構 = **Ragic 引擎(底層)+ ERP 計算引擎 + 預建表單模板**:表單範式讓它統一又可自助,計算層讓它是真 ERP,不是升級版試算表。
> **Q 模組角色收斂**|客戶既然放棄原 ERP,Q 多 ERP 對帳 / 遷移 bridge 不再是核心;至多為 onboarding 一次性資料匯入,不列常駐功能。首波 pilot 集中食品加工 / 團膳。
>
> **市場對照參考**|`docs/08-MES-市場分析.md`(11 家 MES vendor)+ `docs/09-ERP-市場分析.md`(11 家 ERP vendor)+ `docs/10-Ragic-完整功能分析.md`(Ragic 完整功能地圖與定位對照)。
> **背景**|統合 Ragic 側(docs/01)+ 主流 ERP + HR 全景表,產出「Weyver 產品要做的所有事」,支援路線 / 團隊 / 時程 / 定價決策。
> **範圍(v2.0)**|**21 大模組 A–U 全部 Weyver 自建**(recover v1.9 拆出 5 模組)。Weyver 為 Ragic + ERP + MES + ISO 一體 offering,缺一不可。全 TypeScript 自研,含完整 J/K/L/N/P 財會 / 進銷 / 生產 / 成本 / 進出口。
> **單位**|一位資深工程師一個月產能 = 1 人月。
> **兩個尺度**|`MVP 人月` = 能上線收第一批客戶的最低量;`對標 人月` = 達到現有市場水準。
