## 1. B 實測數據(2026-08-04,Playwright computed style,公開頁)

| 站 | 展示字 | h1 | 字距 | 按鈕圓角 | UI 主字級 | 底色 |
|---|---|---|---|---|---|---|
| Linear | Inter Variable | 64px / **wght 510** | −1.408px | 6px 為主 | 12/13/15px | `#08090a` 全深 |
| Mercury | 自製襯線 arcadia | 49px / **wght 480** | normal | pill(40px) | 14/16/18px | 深底行銷面 |
| Stripe | sohne-var | 48px / **wght 300** | −0.96px | 4px | 16px | 白 |
| Attio | interDisplay | 64px / wght 600 | −1.28px | 10px 統一 | 14px 為主 | 白 |

**三條可直接引用的量測結論**|① 大標一律「大字級 × **中間字重(300–600)** × 負字距(−1.5% ~ −2.2%)」——重量感來自尺寸,無人用 900(⚠️ CJK 筆畫密度不同,漢字展示字重可高一檔,但「不要頂到最粗」方向一致);② 按鈕圓角無共識(4/6/10/pill),屬方向自由度;③ UI 主字級 13–15px,與現行 14px 相符,**錦標賽四方向皆不動內文字級**。

## 2-bis. D5 白紙黑字(器物直譯)—— 2026-08-04 追加

> **起因**|D1–D4 被判「預設、Vibe 感(AI)太重」。診斷:四案全部從「premium UI 詞彙庫」生成(浮島/玻璃/grain/發光/漸層印章/eyebrow 大字距)——那個詞彙庫本身就是 AI 味的來源。D5 換**生成來源**:從器物出發(repo 生產實照之 Ragic 現況 + 台灣印刷單據)。
