品牌故事

散落的系統是線頭,Weyver 織成一朵雲

客戶散落的三套 ERP、五份 Excel、十個 Ragic 表單 —— 都是線頭;
Weyver(織雲)是把它們織成一整朵雲的織者。

市場驗證(需求不是猜的)

客戶已在拿 Ragic 取代 ERP,只是撞到「算」的牆

Ragic 自由度極高,客戶已主動在其上重建 ~80% 的 ERP 內容(進銷存 / 採購 / 訂單 / 主檔 / 簡易庫存生產 / 品質 / HR)。但撞到一道明確的牆 ——

Ragic 已擅長的 80%(「填」)

表單 / 子表 / 公式 / 關聯 / 工作流 / 權限 —— 對很多中小廠「幾乎就取代 ERP」。

過不去的 20%(「算」)

會計 GL / 期結 / 成本 / MRP / 庫存估值 —— 是算不是填,表單資料庫做不到。

「你已經在拿 Ragic 取代 ERP 了,只是撞到會計、成本、MRP 那道牆。Weyver 把那道牆(計算層)補上,讓你真正 100% 取代 ERP,還加上 MES + ISO —— 全在同一個 Ragic 範式裡。」
首客 pilot|鮮勇(食品加工 · 既有 Ragic 用戶 · 內部有 3 家 ERP);pipeline 17 家集中食品 / 團膳,平台不限產業。

技術路線(2026-07-16 定案)

全自研 TypeScript 統一全棧 —— 不 fork Odoo

為什麼全自研(4 目標)

  • 安全|統一 TS 型別 end-to-end;100% owned code,無 LGPL 衍生風險
  • 可靠|NestJS 企業級框架標配
  • 性能|Fastify adapter + TS 7 Native 10x compile
  • 好維護|solo dev 單一語言 mental model + AI 產能最大化

技術棧 · 全 OSS

  • TS 7 Native · NestJS 10 + Fastify
  • PostgreSQL 16 · Drizzle(固定)+ Knex(動態 Tier-2)雙軌
  • Next.js 15 + React 19 + Tailwind 4 + shadcn
  • Grid|Glide Data Grid(MIT),非 AG Grid
  • 領域引擎 build-on|GoRules ZEN(規則)· DBOS(workflow)

Clean-room 法律 100% clean|domain 學習純合法來源(IFRS / 教科書 / Odoo 文檔 CC-BY-SA / AI);不 clone 任何 source → 融資 / M&A 供應鏈掃描無 IP 疑慮。

核心差異化(docs/18)

計算層 —— Ragic 過不去、傳統 ERP 才有的「算」

1:1 對應兩層架構:Tier-2 = Ragic 已擅長的 80%;Tier-1 真實表 + 計算層 = 過不去的 20%。計算層蒸餾成規格(純合法):

財會 / 估值

  • GL 複式簿記 + 期結 + 財報
  • AP/AR 沖帳 + 帳齡 + 三方比對
  • 庫存估值 FIFO / 加權 / 移動
  • FX 匯兌損益 · 折舊

成本 / 製造

  • 標準成本 + 差異分析 + BOM 結轉
  • MRP 低階碼 + 淨需求展開
  • 傳票 / 帳務不可變(過帳後開反向沖轉)
  • 金額 numeric(DECIMAL),禁 float 存錢

Q 多 ERP 對帳角色收斂|客戶放棄原 ERP(鼎新 / 千奧 / 正航),至多 onboarding 一次匯入。
