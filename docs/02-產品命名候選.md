# 產品命名決定

## 🎯 主選(2026-07-16 拍板)|Weyver

| 項目 | 內容 |
|---|---|
| **英文品牌** | **Weyver** |
| **讀音** | /ˈweɪ.vər/(如 weaver 少一個 a) |
| **中文品牌** | **織雲** |
| **字源** | Weaver(織者)的變體;繁體「織雲」= 把散落系統整合成一朵雲 |

### 品牌故事(業務簡報第一頁用)

> 客戶散落的三套 ERP、五份 Excel、十個 Ragic 表單 —— 都是**線頭**;**Weyver(織雲)** 是把它們**織成一整朵雲**的織者。

### 為何從 Weft 換到 Weyver(2026-07-16 決策)

1. **Weft 空間已飽和** —— SaaS/AI 空間有 7 個活躍專案在用,其中 `letsweft.com "Weave work that ships"` 是 Scrumban SaaS + MCP for Claude/Cursor,品牌敘事跟我方幾乎一致。
2. **Weft 網域近乎全佔** —— `.com`(1999 老域 locked)/`.io`(Boston 物流公司)/`.tw`(已註冊)/`.ai`(App Store 已有 app)全佔;僅剩 `.app / .dev` 可註冊(對 ERP SaaS 主品牌太弱)。
3. **Weyver 空間乾淨** —— SaaS 空間唯一近音是 Weijver Sport(荷蘭健身俱樂部,不同拼法+不同 Class);`weyver.io + weyver.app` 直接可註冊。

### 已知缺點與對策

- **weyver.com 已被 domain squatter 於 2025-05-11 註冊**(Hostinger)→ broker 議價通常 1–3k USD 可買回;若不急先用 `.io`。
- **中文品牌「織雲」大陸有 Tencent 织云運維平台商標** → 若未來只做台灣市場,TW-only 商標路徑仍可走;**若計畫進大陸,織雲不可用**,需另擇中文品牌。
- 台灣客戶對 Weyver 陌生 → 中文「織雲」day 1 立品牌,英文只做 logo/URL 層。

## 中文品牌決策

**主選:織雲**(day 1 對外用)。

若「戰略決策|是否進大陸」結論是「進」→ 織雲不可用(撞 Tencent 织云),需另擇。備選中文:

| 中文候選 | 優點 | 缺點 |
|---|---|---|
| **織雲** | 動作明確、整合成一朵雲、與 Weyver 語感貼近 | 大陸撞 Tencent 织云 |
| **經緯** | 台灣人熟悉(經緯度、經緯儀)| 商標可能撞既有品牌,需查;與 Weyver 語感疏離 |
| **緯織** | 動詞感、順口 | 意義較弱 |
| **纖網** | SaaS + 網 的融合感 | 相對抽象 |
