# Weyver 向上設計 backlog —— 「凡是要你寫 code 的地方」

> **文件性質**|向上設計的**可執行清單**。不是願望清單,每一條都有**競品官方文件的逐字依據**。
> **產生方法**|把 Ragic 官方繁中文件離線鏡像(582 份)全部剝成純文字、去導覽列,
> 找出所有「使用者想達成某個目的,而官方答案涉及寫程式 / 技術門檻」的位置。
> **為什麼這份清單成立**|Weyver 與 Ragic 承諾的是同一件事 ——「**不用寫程式**」。
> 凡是 Ragic 要你寫 code 的地方,就是它**承諾了卻沒兌現**的位置,也就是 Weyver 該向上的地方。
> 見 AGENTS.md〈🚫 第一約束:不用寫 code〉。
> **版本**|2026-08-02 v1 · 查證日期 2026-08-02

---

## 0. 一句話

掃到 **23 條真 pro-code**(其中 13 篇 KB / 手冊**直接貼 JavaScript 原始碼**要使用者自己改),
業務價值高的 **8 條**;另有 12 處官方明說做不到、10 項它已用視覺化工具解掉(**不得重複宣稱**)。

⚠️ **措辭紀律**|本檔為**內部** backlog。對外一律正面表述(我們讓你不用寫程式就做得到),
不講對手做不到 —— 見 docs/30 §6。

## 1. 業務價值高(8 條)

| # | 使用者想做的事 | 官方答案(逐字) | 門檻 | Weyver 能否 no-code |
|---|---|---|---|---|
| 1 | **算出這批貨的成本、結出庫存餘額** | 「所有表單都可以觸發 Ragic 的伺服器端 JavaScript 工作流程引擎來執行複雜的業務邏輯,如**計算成本和發布庫存餘額**。基本上,任何 Ragic 現有功能無法覆蓋的複雜業務邏輯都可以透過伺服器端程式來實現」`doc/29` | 寫 JS | **部分**。FIFO / 加權平均 / 移動平均是**有限個已知演算法**,可做成「選估值方法 + 語意標記綁欄位」的預建模型;任意成本分攤仍需規則表達(視覺化決策表),無法完全消除 |
| 2 | **記帳、開發票、算稅** | KB 標題逐字:「如何在 Ragic 建立訂單時,自動在 **Xero** 開一筆對應的發票?」;且「Xero 在 Zapier 內是一個 Premium app,必須購買 Zapier 的付費授權」`doc-kb/259` | 打 API + 付費第三方 | **可**。這是官方把帳務層指向外部產品,直接是 R2 靶心 |
| 3 | 🔴 **讓合計不要算錯** | 「資料儲存時觸發的相關表單公式重算會有**資料筆數限制為 2000 筆**,若需重算的資料超過系統限制,**所有相關表單資料都不會進行公式重算**…改成針對相關表單**撰寫**每日自動執行公式重算的**程式**」`doc-kb/281`;另 `doc-kb/131`「可以考慮**利用程式**自動執行每日公式重算」、`doc-kb/163`「利用程式,在資料儲存完成後自動執行公式重算」 | 寫 JS(還要查 Key Field ID、表單路徑) | **可**。宣告式依賴圖自動失效,**無筆數上限**、連設定項都不該有 |
| 4 | 存檔後自動帶出關聯資料 / 每日同步 | 「可以考慮利用程式自動執行此操作」`doc-kb/214`、`doc-kb/260` | 寫 JS | **可**。屬觸發時機宣告 |
| 5 | 對接自家 ERP / 外部系統(雙向) | 「有以下幾種**不用另外寫程式**的方法以及 **2 種需要客製化程式**的做法」`doc/98` | 寫 JS / 寫 client | **部分**。視覺化連接器 + 映射表可涵蓋大宗,長尾仍需 transform 表達 |
| 6 | 單據結案後自動鎖住不給改 | 「此功能目前還在**規劃中**…在功能上線之前,可暫時以如下方式替代」→ 條件公式 + 貼 JS `entry.lock()`;且「上鎖的紀錄**不會顯示在歷史編輯紀錄中**」`doc-kb/215` | 寫 JS | **可**。條件式唯讀 / 鎖定是純宣告規則,**且必須進稽核軌** |
| 7 | 列印出公司格式的單據 | 「只有開放**系統管理者 SYSAdmin** 有建立與設定客製列印報表範本的權限」,要在 Word/Excel/PPT 裡寫欄位參數,子表格得「寫 `[i]` 和 `[i+1]` 兩列」`doc/138` | 範本語法 + 管理員限定 | **可**。所見即所得單據設計器,綁欄位不綁語法(接 UP-3c「畫布就是紙」) |
| 8 | 建重複客戶時只提醒、仍可存 | 貼 `checkIfUniqueFieldValue()` 到 Global + Post-workflow `doc-kb/253` | 寫 JS | **可**。「唯一性:阻擋 / 警告」應是欄位屬性的一個選項 |

## 2. 業務價值中(9 條 · 摘要)

資料留存 N 天自動刪(PDPA)—— 貼 `db.deleteOldRecords()`,**上限 500 筆且不進回收桶、無法復原**`doc-kb/202` ·
記錄單一欄位最後改動時間 —— 兩段各 20 行 JS + 查 KeyField `doc-kb/155` ·
禁止管理員在某表單新增 —— 貼 Pre-workflow `doc-kb/193` ·
同步到自家 SQL —— 要開防火牆 port、單向 `doc/141` ·
複雜篩選 —— 「使用**正規表示法**來搜尋,只要在開頭加入 `regex:`」`doc-user/15` ·
推 LINE 訊息 —— 註冊官方帳號 + Messaging API + Channel access token `doc-kb/300` ·
更深客製 —— 「自行撰寫**客製化 jsp**」且限最高價方案 `doc-kb/205` ·
公司設定找不到功能 —— 「請寄信給 Ragic Support,我們會**手動幫您更新系統表單**」`doc/56` ·
私有主機開 AI / MCP —— 改 `ragic.properties` 參數 `doc/113`

## 3. 官方明說做不到的(另一種向上機會)

樞紐分析「可分析的行數上限為 **1000 行**」`doc/22` · 條件式自動上鎖「規劃中」`doc-kb/215` ·
定期網址匯入「尚不支援**子表格**匯入」`doc/73` · Looker Studio「不支援子表格資料」`doc/146` ·
MCP「只提供資料讀取功能」`doc/180` · IFTTT 無法「Gmail 收信 → Ragic 建資料」`doc/135` ·
多選欄位不支援公式 `doc/124` · 設計模式大量設定「不支援復原」`doc/143` ·
App 不支援改表單設計 / 產報表 / 批次匯入匯出 / JS Workflow `doc-app/11` ·
私有主機不支援 Stripe / 簡訊 / Looker / 跨帳號複製器 `doc/113`

## 4. ⚠️ 它已用視覺化工具解掉的(**不得重複宣稱為差異化**)

Workflow 產生器(**但仍要自己改欄位 ID,只解一半**)`doc/125` · 六種動作按鈕 + 儲存時自動執行 `doc/68` ·
條件式格式自動唯讀 · 簽核完自動執行按鈕 · 拋轉的子表篩選/分群 `doc-kb/305` ·
**AI 產生正規表示法**(輸入檢查小幫手)`doc/24` · **公式小幫手** `doc/26` ·
**AI Agent**(自動檢查輸入 / 自動填欄 / 寄信回信)`doc/173` ·
Zapier / Make / n8n / IFTTT / SurveyCake / Looker / MCP 七種免寫程式串接 `doc/98`

> **值得記下的一句**|`doc-kb/305` 官方逐字:「部分自動化設定位於**進階選項中,較不易被發現**,
> **可能導致使用者額外花時間撰寫 Script**。」—— 它知道使用者在寫 code,但把原因歸為「功能太難找」。
> **我們的判斷不同**:有些確實是可發現性問題,但 #1 / #3 那類是**引擎能力缺口**,再好找也還是要寫程式。

## 5. 🔴 若只能做三件事

| 順位 | 項目 | 為什麼是這三件 |
|:-:|---|---|
| **1** | **重算與同步的宣告式觸發** | `doc-kb/131 / 163 / 214 / 260 / 281` **五篇 KB 全在教使用者寫 JS**,補引擎沒自動做的事,還帶 **2000 筆上限 —— 超過就整批不重算**。這不是方便性問題,是**正確性問題**:合計會安靜地算錯。用依賴圖自動失效可**一次消滅五篇文件**,而且是**客戶當場感知得到**的差距。ROI 最高 |
| **2** | **計算層的 no-code 綁定**(成本 / 估值 / 餘額 / 期末結轉) | `doc/29` 逐字承認的破口,也是官方把帳務指向 **Xero** 的原因。做掉它才成立「取代 ERP」。⚠️ 綁定**必須自助化**,否則定位崩掉(AGENTS.md 第一約束) |
| **3** | **視覺化規則引擎(條件 → 動作)** | 上鎖 `doc-kb/215` / 重複警告 `doc-kb/253` / 權限阻擋 `doc-kb/193` / 欄位稽核 `doc-kb/155` **是同一件事的四個變形**。一個 GoRules ZEN 決策表全吃(docs/20 已選型),並順帶接住「任意商業邏輯」的長尾 |
