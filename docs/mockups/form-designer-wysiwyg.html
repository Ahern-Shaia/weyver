v1 → v2 改了什麼

項目v1為什麼改
畫布模型th|td|th|td 流式表格 引擎的版面 metadata 是 col / row / colSpan 座標。流式表格排不出「第 3 欄起、寬 4 格」, 也畫不出空白座標 —— 稿子與可實作的東西不是同一件事。
填單屏缺席(兩屏都是設計) 「設計即所見」的另一半在填單。只畫設計屏,等於只證明了一半 —— 實際跑起來才發現斷掉的正是填單側。
示例值底紋45° 斜紋淡底 每一格都鋪斜紋在整屏尺度上是雜訊;ink-3 + 型別圖示已足以讀成「非真值」。 此為對 v1 的推翻,不是實作偷工。
拖曳把手未畫 把手若佔一個實體欄,設計與填單的值格起點就差 20px —— 主張當場失效。改為疊在標籤格左緣。
型別如何呈現未定 值格左側 Lucide 圖示。不用文字標籤:那會讓每列多一塊與填單無關的內容。
