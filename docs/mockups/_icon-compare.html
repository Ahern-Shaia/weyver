兩個反對「彩色圖示」的理由,不是品味
① 物理:14px 下多色會糊成一團,顏色資訊消失 —— 這是可量的,不是喜好。
② 證據:共識 R9(NocoDB 實測 全部單色深灰)+ docs/38 §3.3 把「圖示多套混用(線性 + 彩色迷你插畫 + 卡通頭像)」列為舊感來源(Ragic 三套 / Odoo)。

⚠️ C 案的誠實聲明:那是用 Lucide 模擬 Phosphor 的 duotone 技法,不是真的 Phosphor 字形。Phosphor 未安裝,我不為了做對照而加相依。 真要採用,代價是換掉整套 1500+ 圖示並重對所有既有畫面。


🔴 E 案(決策方選定 2026-08-08)= B + D 混合:有天然字符的用字符(T ¶ # $ @ ƒx,6/16), 其餘用象形 —— 但兩者都吃分組色、同尺寸。
這是關鍵:D 單獨看是「兩套系統混用」(§3.3 的舊感來源), 而一旦兩者共用同一組分組色與同一個字級,它就不是兩套系統,是同一套系統的兩種字身 —— 就像一份排版裡同時有數字與文字,沒有人會說那是混用。
D 案是今天研究本身冒出來的 —— NocoDB 的型別圖示實測是字符與象形混用 (T 文字、# 數字是字符,迴紋針 / 信封 / 電話才是象形), 而字符在小尺寸比象形清楚得多。這一案零成本、零新相依。
