01品牌故事
客戶散落的三套 ERP、五份 Excel、十個 Ragic 表單 —— 都是線頭;Weyver(織雲) 是把它們織成一整朵雲的織者。一個平台,看得見全貌。
隱喻邊界|織/雲存於敘事與命名,不外顯為介面裝飾。產品內禁雲朵/漸層;介面的品牌感來自嚴謹的結構本身(見 §06)。

07Do & Don't(品牌層)

Do — 嚴謹企業級

  • 一律「Weyver(織雲)」,中文 day 1 主打
  • 品牌隱喻(織/雲)存於敘事與命名
  • 產品內用嚴謹結構表達品牌
  • 三主題 = 一套系統的可切換配色
  • IBM Plex 貫穿產品與物料;數字 Mono + tabular
  • Sober、務實、內行的文案

Don't — 避開

  • 自稱 Ragic clone / 複製 / 類 Ragic
  • 把雲/織畫進產品介面當裝飾
  • 產品內加漸層 hero / pill / 陰影
  • 把三色講成三個品牌 / 隨意混色
  • 物料換字型(Inter / 系統預設)
  • 行銷腔、裝可愛、空喊顛覆
