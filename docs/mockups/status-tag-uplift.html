A 現況

B 推薦
已了結 → 中性灰章(退背景);待審核琥/退回紅 → 一眼跳出來。把注意力導向該處理的 = premium 資料工具(Linear/Height 都這樣)。仍是帶框方角章,零裝飾。
C 純文字
連框都省,最高密度。適合欄位極多、狀態次要的密表;但少了「章」的邊界感,重要狀態較不跳。
