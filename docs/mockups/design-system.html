Brand Identity · Design System

Weyver 織雲 設計系統

企業級多產業製造平台的統一視覺語言。所有前端產出以此為單一真實來源 —— 對齊 Dynamics / Ramp / Sigma 級企業 SaaS 基準:精準、克制、資料導向、可信賴。

品牌故事　客戶散落的三套 ERP、五份 Excel、十個 Ragic 表單,都是線頭;Weyver(織雲)把它們織成一整朵雲 —— 一個平台,看得見全貌。品牌隱喻存於敘事與命名,不外顯為裝飾;介面本身保持企業級的克制與精準。

設計原則

四條原則貫穿所有畫面決策。若一個設計不服務這四點,就不做。

整合 · 一站式

Ragic 表單 + ERP + MES + ISO 在同一 shell、同一 token。切模組像切分頁,不像換系統。跨模組資料流動可見。

精準 · 克制

中性灰白為主,深海青只點在重點(active / 連結 / 主行動 / 關鍵數字)。細邊框 + 極輕陰影,不用漸層與軟陰影。

資料導向

KPI、圖表、資料表為主體。數字一律 tabular-nums 對齊。密集但井然有序,不塞爆、不裝飾。

可信賴 · 企業級

資料更新時間戳、同步狀態、篩選控制等信任訊號常駐。嚴肅、有力,不消費風、不裝可愛。

色彩

品牌深海青 #0C5F73 —— 台灣 ERP 競品清一色藍,此色差異化,兼具精密儀器感與「雲/水」意象。色彩走語意 token,禁硬編 hex。

Do & Don't

從 6 版迭代中得到的鐵則。左為企業級標準,右為要避開的消費級 / 後台陷阱。

Do — 企業級

  • 頂欄 + 左導航 + 內容的專業 chrome
  • 資料更新時間戳、同步狀態、篩選等信任訊號
  • 細邊框 + 極輕陰影建立深度
  • 中性灰白為主,深海青精準點綴
  • KPI / 圖表 / 資料表資料導向,數字 tabular-nums
  • 狀態 = 顏色 + dot + 文字(WCAG AA)
  • outline icon,一致筆畫,無 emoji

Don't — 避開

  • in-app 漸層 hero banner(那是行銷頁手法)
  • 織雲等品牌隱喻外顯為畫面裝飾
  • 暖色漸層卡、彩色 icon 塊(消費風)
  • 大圓角 + 軟陰影堆疊(顯得消費 / 廉價)
  • 整片灰色資料表無層次(generic 後台感)
  • 斑馬紋列(ERP legacy)
  • 切換工作區 UI(多租戶單一租戶,無此情境)
