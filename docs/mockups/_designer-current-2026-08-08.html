4 · 畫這份稿的時候發現的(全部是現況的問題,不是提案)

  1. 🔴 三種存檔心智混在同一欄面板,而畫面上沒有任何記號區分。 基本設定 8 項是草稿(跟畫布一起按「儲存版面」)· 選項與帶入對映各自有儲存鈕 · 日期格式 / 條碼 / 文字遮罩 / 連動選項改了就立刻送出。 程式碼註解說明了理由(選項會改寫既有記錄),但使用者看不到這個分界。
  2. 🔴 「不可重複」後端做完了,前端沒有任何入口 —— 這是第一約束違規。
    後端齊全:field_def.is_unique(migration 0000)· form-specs.ts:24 收得到 · API 回傳 · record.service 連「違反後加約束」都處理了。
    前端:schemas.ts:86 有型別,其餘只出現在測試 fixture —— 零 writer、零 reader。 使用者想設唯一值,唯一路徑是打 API。與 task #51「文字遮罩的設計器 UI 缺席」同一形狀。
  3. 🔴 「必填」建立之後改不了。 加欄卡可以勾,但欄位的 PATCH 端點只有 type / options / load-map / display / position —— 沒有改 required 的路徑。忘了勾就只能刪掉重建。 (條件式格式的「設為必填」是條件式效果,不是改這個欄位的基本屬性。)
  4. ⚠️ 所以 weyver-v2.html 屬性面板上的「必填 / 不可重複」不是畫錯,是提案 —— 它畫的正好是這兩個該補的入口。本稿(現況)刻意不畫,兩份的差別就是缺口本身。
  5. 只有新增沒有編輯,三處同型:自訂按鈕(只有 🗑)· 簽核流程(連刪除與啟停都沒有)· 標籤。
  6. 漏翻譯:按鈕清單直接顯示 updateSelf / pushTo / openUrl,同一面板其他地方全中文。
  7. 兩處 Markdown 星號沒 render,畫面上會看到裸露的 ** (帶入對映說明、格式遮罩說明)。本稿照現況畫,沒有幫它修掉。
  8. 全形 / 半形括號不一致:「提示文字(placeholder)」半形 vs 「欄位說明（? 圖示)」「隱藏（排版層,非權限)」「公式（P1,暫不套)」全形。同一個面板內混用。
  9. 預設值的「公式」可以選但不會生效 —— 選項字面就是「公式（P1,暫不套)」。
