Weyver — 破壞性重構探索(3 方向)

「像內部後台」的病根 = 外框(chrome)沒被設計、全平灰、沒有 POV。三版都保持資料區嚴謹(帶框方角章、tabular、真 Lucide、狀態列),差別在外框的設計語言——這才是產品感/企業感的來源。每版有 thesis;選定後落 code + 重寫 docs/14。

V1

深色駕駛艙

Thesis:深色 chrome + 亮資料 = 通用「正經 SaaS 產品」訊號(Linear / Vercel / Retool / Datadog / Sigma)。

為何解「後台感」:深外框把「應用」和「你的資料」分層,一眼就不是陽春灰底 admin;資料區照樣高密度嚴謹。

V2

精緻明亮(Stripe / Mercury 級)

Thesis:亮色也能高級——靠字階、間距紀律、克制,不是裝飾。證明「不加深色」也不土。

為何解「後台感」:大標題字階 + 乾淨白 + 精準 hairline = 像真設計團隊做的,不是工程師隨手後台。

V3

現代工作站(Notion / Attio / Height 味)

Thesis:一個鮮明品牌 accent(靛藍)+ 柔和現代面板 + 工作區分組側欄,像協作工作站不是表格 dump。

為何解「後台感」:有記憶點的 accent + 現代圓潤 + 側欄組織感 = 讀成「有人設計的現代 app」。(accent 可換回 Weyver 深藍/深海青,僅示範個性)
