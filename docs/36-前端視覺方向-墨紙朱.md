## 0. v1 為什麼失敗(誠實檢討)

v1(docs/35)把「不違反 docs/14 現行規範」當成了隱含門檻:保留全部 token、保留殼的形狀、保留零陰影、保留 14px 密度,只加了 serif 標題與一枚綠色印記。**在一個以禁令構成的系統裡做加法,結果必然是「幾乎沒有變化」** —— 因為所有能造成視覺差異的手段(深度、明暗、材質、尺度)都還在禁令清單上。

決策方的指令是「放棄現況的視覺規範」——正確的讀法是:**規範是這次設計的產出,不是輸入。** v2 據此重來:從三個材質出發建立整套視覺,舊禁令逐條重審,能留的留、該翻的翻,每條附理由。

## 1. 設計主意 v2|三材質系統:墨・紙・朱

一句話:**墨色的工作檯、發光的紙、朱紅的印。**

| 材質 | 承載 | 視覺性質 | Rationale |
|---|---|---|---|
| **墨(chrome)** | 殼:導覽、狀態列、桌面 | 深墨色(`#14181d` 家族)、微 grain、light-on-dark 文字、玻璃質浮島 | 深色 chrome 框住發光內容 = 專業創作工具的既有語言(Linear / Adobe 全家 / DaVinci):**工具退暗,作品發光**。Weyver 的「作品」就是單據 |
| **紙(document)** | 單據:記錄頁、欄位表、列印 | 暖白(`#fdfcf8`)、serif 展示字、細規線、實體深度(浮起 + 疊頁) | docs/14 既有定位「長得像客戶原本的紙本單據」做到底:紙不只是白色矩形,紙有**明度、溫度、厚度、疊層** |
| **朱(seal)** | 不可變狀態:過帳、簽核完成、作廢 | 印泥朱紅(`#c23a2a` 家族)、方章、白字 | 台灣商業文件的「已成立且不可回改」以**紅印**表達 —— 收訖、付訖、過帳章全是紅的。v1 用綠色狀態章是把印記降級回 badge;**朱紅才是這個文化裡印的顏色** |

**為什麼這是差異化而不是裝飾**|競品(Ragic / Odoo / 鼎新)全部是「白底 + 藍 chrome」的同一片海。墨檯上一張發光的紙、蓋著朱印 —— 這個畫面**一眼可辨識、可記憶、可描述**("那個深色桌面上有張紙的系統"),且每個元素都錨定在使用者的職業現實(公文書、帳簿、印章),不是借來的美學。

## 2. 被推翻的舊禁令 × 替代 rationale(逐條)

| docs/14 舊禁令 | v2 處置 | 替代 rationale |
|---|---|---|
| 禁 resting 陰影 | **推翻(限紙)**|紙用大擴散、低不透明度的 ambient 陰影浮在墨檯上 | 陰影在這裡不是「卡片裝飾」而是**物理隱喻的必要條件**:紙放在桌上本來就有影子。單一光源、只有「紙」這一種元素可用 —— 不是回到人人有陰影的 SaaS |
| 禁深色大面積 chrome(v3 教訓) | **推翻(但與 v3 不同)** | v3 失敗的是「**主色**深藍側欄 + 其餘照舊」= AdminLTE 原型。v2 是**全幅中性墨色工作檯**(rail + 桌面 + 狀態列一體),且深色的目的為襯亮紙 —— 引用對象是 Linear / Adobe 的深 chrome 亮畫布,不是 admin template 的藍側欄 |
| 字體 Inter 鎖定 | **推翻**|內文回歸 **IBM Plex Sans + Noto Sans TC**;單據展示層 **Noto Serif TC**(700/900) | IBM Plex 本是 `docs/26` 品牌手冊的原選(2026-08-02 才換 Inter);Inter 是「AI 預設」曾被自家文件點名。Plex 的工程性格 + 宋體的公文性格,是有出處的配對 |
| 動效近乎無(Carbon productive 70–150ms) | **部分推翻**|保留控件層 productive 時值;**新增編排層**:進場 stagger fade-up(600–800ms 自訂 bezier)、印章落印動畫(一次性) | 動效分兩層:控件回饋要快(留);**空間敘事**(紙浮現、印落下)是材質系統的一部分,沒有它「紙」只是色塊。全部受 `prefers-reduced-motion` 管 |
| 大留白 hero 禁 | **推翻(限墨檯層)**|墨檯上的巨觀留白拉大(紙的周圍要有桌面);**紙內密度不變** | 留白的位置錯了才廉價:單據內容仍是高密度帳簿(心智模型);呼吸的是**桌面**,不是資料 |
| 圓角上限 6px | **調整**|墨檯層浮島 14–18px;紙 12px;紙內控件維持 3–6px | 圓角語意分層:實體物件(紙、浮島)用實體的圓角;資料元件維持銳利 |
| 禁 pill | **維持** | 沒有出現的理由;sober 語氣不變 |
| 禁漸層(裝飾用) | **大致維持**|僅墨檯允許極低調 radial 明度變化(vignette)與 grain 0.04 | 均勻的純色深底會顯得數位而死;grain 與 vignette 是「檯面」的材質,**紙面一律禁**(列印保真) |
| 儀表板當首頁禁 | **維持** | docs/24 心智模型,不可動 |

**工程層全部保留**|`--base-brand` 推導、三主題白牌、contrast/hex CI、a11y、動效 token 機制 —— 換的是值與版型,不是機制。**朱為跨主題固定色**(文化色,不隨白牌換);主色(navy/teal/graphite)繼續承載互動(連結、主按鈕)。朱與主色的分工:**朱=文件狀態語言,主色=互動語言**,兩者不同場合出現,不構成雙 accent 打架。

## 4. Kitsch 防線(不做的)

- 不做紙紋理 / 泛黃 / 摺角 / 咖啡漬 —— 紙只取明度、溫度、深度三性質。
- 朱印不做印泥暈染、不做隨機旋轉(作廢章的斜蓋是唯一語意化例外)。
- grain 只在墨檯(fixed、pointer-events-none、opacity ≤0.04),紙面與資料區禁。
- 織雲隱喻仍不進 chrome(docs/26)。
- 紙內資料密度不放鬆 —— 高密度帳簿是專業性的來源,呼吸的是桌面。
