## 1. 品牌策略

### 1.1 品牌本質(一句話)

> **Weyver 是把企業散落的系統,織成一個嚴謹、可信賴的表單平台。**

### 1.2 定位陳述(positioning statement)

> 對**放棄多套 ERP / Excel / Ragic、想在一個平台上作業的台灣中小製造業**而言,
> **Weyver(織雲)** 是一個**以 Ragic 表單範式為基底、補上真會計「算」力、並融合 MES + ISO 的一站式企業平台** ——
> 不同於**主流 ERP(嚇人、僵硬)**與 **Ragic(彈性但算不了)**,Weyver **既自助彈性、又是真 ERP**,而且**四塊在同一個工作區,不需切換系統**。

### 1.3 使命 / 願景

- **使命**|讓中小製造業「不再開五個系統視窗切換」;用一套表單範式管完採購、生產、品保、財會。
- **願景**|成為台灣中小製造業「取代 ERP」的預設平台;既有 Ragic 用戶的無痛升級路徑。

### 1.4 品牌支柱(brand pillars — 一切表達回扣這四點)

| 支柱 | 意義 | 在產品/物料的證據 |
|---|---|---|
| **一體(Woven)** | 散落系統織成一個工作區;切模組像切表單不像切系統 | 同一 shell / topbar / token;能力織入表單非分立 tab(`docs/24 §2`) |
| **嚴謹(Rigorous)** | 企業級的信任來自結構訊號 | 全框線欄位表 · 借貸平衡斷言 · 時間戳到秒 · 稽核記錄(`docs/14 v2`) |
| **自助(Self-serve)** | 客戶自己建、自己填(Ragic 範式) | 表單設計器 · 30+ 欄位型別 · 用 Excel 建表(`docs/24 §0`) |
| **可信(Trustworthy)** | 資料可驗證、可追溯、不消費風 | 時間戳 / 版本 / 還原 / 狀態列;克制無裝飾(`docs/14 §0`) |

### 1.5 目標對象

- **主**|台灣中小製造業(食品加工 / 團膳為首波),既有 Ragic 用戶或用 Excel 補洞 ERP 者。
- **每日使用者角色**|操作員(現場/平板)· 會計(單據/對帳)· 品保/ISO 專員 · 主管(彙總)。
- **決策者**|廠內資訊窗口 / 老闆 / 廠長。

### 1.6 競品對照(品牌定位座標)

| 對照 | 他們的印象 | Weyver 的差異化姿態 |
|---|---|---|
| SAP / NetSuite | 嚴謹但嚇人、僵硬、貴 | 一樣嚴謹,但親近、自助、TW 在地 |
| 鼎新 / 正航(TIPTOP) | 在地但停在 2005-2010 UI | 同在地脈絡,現代化嚴謹 UI |
| Ragic / Airtable | 彈性但「算」不了、視覺舊 | 保留彈性 + 補計算層 + 現代嚴謹視覺 |
| 通用 SaaS(Notion 風) | 漂亮但不像正經企業系統 | 刻意反通用 SaaS(全框線 / 密度 / 信任訊號) |

## 2. 品牌故事與隱喻(織雲)

### 2.1 核心敘事(業務簡報第一頁)

> 客戶散落的三套 ERP、五份 Excel、十個 Ragic 表單 —— 都是**線頭**;
> **Weyver(織雲)** 是把它們**織成一整朵雲**的織者。一個平台,看得見全貌。

### 2.2 隱喻的邊界(關鍵鐵則)

- **品牌隱喻(織 / 雲 / 線)存於敘事、命名、對外物料;不外顯為產品介面的裝飾。**
- 產品內**禁**雲朵插畫、織紋背景、漸層 hero(`docs/14 §0 反面`)。介面的品牌感來自**嚴謹的結構本身**(見 §7.2)。
- 換言之:**行銷可以講「雲」,產品只做「嚴謹」。**

### 2.3 電梯簡報(依場合)

- **一句**|「你已經在拿 Ragic 取代 ERP,只是撞到會計、成本、MRP 那道牆;Weyver 把牆補上。」
- **三句**|Ragic 讓中小廠自己把八成 ERP 內容搬上雲,但算不了 GL / 成本 / MRP。Weyver 用同一表單範式補上「算」,再融合 MES + ISO。四塊在一個工作區,不再切系統。

## 3. 命名(Naming)

### 3.1 Weyver

- **拼寫**|`Weyver`(首字大寫,其餘小寫)。
- **讀音**|/ˈweɪ.vər/(如 weaver 少一個 a)。
- **字源**|Weaver(織者)之變體 —— 呼應「把線頭織成雲」的織者角色。

### 3.2 織雲(中文)

- **用法**|台灣市場 **day 1 對外主打中文「織雲」**;英文 Weyver 主要用於 logo / URL / 國際層。
- **意義**|把散落系統整合成一朵雲。

### 3.3 讀音 / 拼寫規範(正 / 誤)

| ✅ 正確 | ❌ 錯誤 |
|---|---|
| Weyver | WeYver · WEYVER · weyver(句中除外)· Weaver · Weyber · Weijver |
| 織雲 | 織云(簡體,大陸市場另議)· 織緯(舊名 Weft,已降備選) |
| Weyver(織雲) | Ragic clone · Ragic 版 · 類 Ragic(法律紅線,§3.4) |

### 3.4 商標與法律紅線(對照 `docs/02`)

- **正式檢索未完成**|TIPO(Weyver + 織雲,Class 09 / 42;近似音 Weijver / Weaver / Weyber)+ USPTO(Class 009 / 042)**待檢索**;定案前品牌可用性未定。

## 4. 標誌系統(Logo & Mark)

> 實作色值見 `docs/14 §2.2`(三主題 `--primary`);此處定義形狀與用法。

### 4.1 App Mark(W 方塊)—— 主標

- **構成**|**方角圓角矩形**(圓角 = `--radius-sm` 3px)+ **主色實底** + **白色大寫「W」**(IBM Plex Sans,700 粗)。
- **淨空**|四邊 ≥ 標記高度 25% 之留白。
- **最小尺寸**|螢幕 16px、印刷 5mm。
- **不加**|**漸層**、外框、光暈、雲朵裝飾、resting 陰影。品牌塊平色、無陰影(呼應 `docs/14 §0.1` v3:陰影僅 overlay 分層,漸層一律禁)。

### 4.2 Wordmark(字標)

- **組合**|`Weyver` +(可選)較小、次要色 `織雲`。
- **字型**|IBM Plex Sans,**Weyver** 600、`織雲` 用 IBM Plex Sans TC 400 灰(`--ink-3`)。
- **不**|不改字型、不加字距特效、不斜體。

### 4.3 Lockup(鎖定組合)

- **水平**|[W 方塊] + 間距(≈ 標記寬 40%)+ `Weyver 織雲`。
- **僅標記**|favicon / app icon / topbar(空間受限時)。

### 4.4 三主題下的標誌

標記填色 = 當前主題 `--primary`(深藍 / 深海青 / 石墨)。**同一形狀,只換填色**;白牌客戶可換為其自訂主題色(§5.1、§9.6)。

### 4.5 深底 / 淺底

- **淺底**(預設)|主色實底方塊 + 白 W。
- **深底 / 反白**|白色或極淺方塊 + 主色 W;或全白線框 + 白 W。
- **單色**|純黑 / 純白版本供傳真 / 蓋印 / 燙印。

### 4.6 誤用(禁止)

不擠壓變形 · 不換色相(主題色以外)· 不加陰影漸層 · 不置於雜亂照片上 · 不與雲/織圖案疊加 · 不旋轉。

## 5. 色彩(Color)

> **權威色票以 `docs/14 §2` 為準**;此處定義**品牌用色策略**與代表色。

### 5.1 三配色主題策略(一套系統、可切換)

Weyver 是**一套設計系統、三個官方配色主題**(`[data-theme]` 語意 token,`docs/14 §2.2`):

| 主題 | 主色 | 深階 | 淡底 | 性格 / 適用 |
|---|---|---|---|---|
| **深藍(navy,預設)** | `#1E4E79` | `#173D5F` | `#E7EEF5` | 品類母語、企業可信;**對外品牌預設** |
| **深海青(teal)** | `#0C5F73` | `#094A5A` | `#E6F0F3` | 精密 + 雲/水意象、與台灣競品差異化;**織雲故事色** |
| **石墨(graphite)** | `#313131` | `#1F1F1F` | `#ECECEA` | 中性工業、讓資料/狀態最跳 |

- **產品內**|三主題皆為官方,使用者/租戶可切;**白牌**客戶可換自訂主色(語意 token 換值即全站生效)。
- **對外品牌(logo / 名片 / 官網 / 簡報)**|用**單一代表色**以維持識別;預設 **深藍 #1E4E79**(見 §11 待拍板)。

### 5.2 品牌代表色 vs 產品主題色

- **品牌代表色**|對外識別的單一色(§5.1 建議深藍)。
- **產品主題色**|`--primary`,可切換,是**產品功能(白牌)**不是品牌分裂。
- **論述**|Weyver 的識別由「**系統**」定義(IBM Plex + W 方塊 + 全框線嚴謹 + 這組色階),不只由單一色相;三主題強化「可自訂、白牌就緒」的產品訊息。

### 5.3 品牌相關色票(節錄;完整見 `docs/14 §2`)

- **主色(三主題)**|§5.1。
- **中性(結構)**|`--ink #14181D` · `--ink-2 #3E4854` · `--ink-3 #6B7684` · `--ink-4 #98A2AE` · `--surface #E8EAED` · `--card #FFFFFF` · `--head #F2F4F6` · `--label #EEF1F4` · `--line #C9CFD6` · `--cell #D5DAE0`。
- **狀態(帶框章)**|`--ok #1A7A43` · `--wn #9A5B00` · `--er #B3261E` · `--nt #4A5560`(各含 line / tint 三值)。
- **功能(跨主題共用)**|連結 `--link #0B5CAB` · 公式 `--fx #0B6B5D` · 關聯 `--rel #5B3FA8`。

### 5.4 對外行銷 vs 產品內 用色差異

| | 產品內 | 對外行銷 |
|---|---|---|
| 主色用量 | 極克制(分段條 / active / 主行動) | 可較主動(封面 / 標題 / 圖表) |
| 漸層 | 禁 | 極克制可用(封面背景,不進產品截圖) |
| 織/雲意象 | 禁 | 可(僅敘事層 / 抽象,不俗豔) |
| 底色 | `--surface` 中性 | 白 / 極淺中性 |

### 5.5 對比與無障礙

- 三主色白字對比皆 **≥ 7:1**(AA/AAA 過關,`docs/14 §2.2`)。
- 內文對比 ≥ AA 4.5:1;狀態一律**顏色 + 文字**雙編碼(不單靠色)。

## 6. 字型(Typography)

> 字級/字重規範見 `docs/14 §2.5`;此處定義品牌選型與理由。

### 6.1 IBM Plex 超家族(鎖定)

| 用途 | 字型 |
|---|---|
| 拉丁 / UI / 標題 / 內文 | **IBM Plex Sans** |
| 繁體中文 | **IBM Plex Sans TC** |
| 數字 / 金額 / 批號 / 代碼 / 時間戳 | **IBM Plex Mono**(+ `tnum` tabular) |

**為何 IBM Plex(品牌理由)**|
1. IBM 委託設計之**企業識別字體**,為企業軟體而生,工程/精密性格呼應製造業。
2. **一套設計語言貫穿 Latin + 繁中 + Mono**(同源超家族)—— 系統化一致性正是「讀起來企業級」的關鍵;非拼裝(Inter + Noto)。
3. **Plex Mono slab 襯線**|批號 `BN-0716-A` / GL 代碼 / 金額 tabular 對齊辨識度強。
4. **OSS(OFL)**|符合全 OSS 策略。
5. **明確不是 Inter**|脫離「AI 生成預設」訊號。

### 6.2 品牌字型層級(重點)

Logo `Weyver` = Plex Sans 600–700;`織雲` = Plex Sans TC 400 灰。內文 12.5px、標題見 `docs/14 §2.5`。**所有數字一律 Mono + tabular**(品牌簽名之一)。

### 6.3 對外物料 vs 產品

- **產品**|嚴格照 `docs/14 §2.5`(12.5px 密度基準;長文 ≥14px)。
- **對外(簡報 / 官網)**|可放大字級、拉開層級,但**字型不換**(仍 IBM Plex),維持一致識別。

## 7. 圖形語言(Iconography & Graphic)

### 7.1 圖示

- **Lucide**(outline,stroke ~1.5),**功能性使用為主,不作裝飾**。
- **禁 emoji、禁彩色 icon 塊**(`docs/14 §4`)。

### 7.2 視覺簽名 = 全框線(而非雲朵)

- Weyver 的**產品視覺簽名 = 全框線欄位表 + 扁平主色分段條**(`docs/14 §3.2`)。這本身就是圖形語言:讀起來像「嚴謹單據」,是**織(格線縱橫)的抽象表現**,勝過任何雲朵插畫。
- 「織」的隱喻若要在對外物料視覺化,採**抽象格線 / 交織線條**(細、克制、單色),不用具象雲朵、不用漸層雲霧。

### 7.3 攝影 / 插畫(對外)

若需影像:食品加工 / 產線 / 冷鏈 之**真實、克制、非炫技**攝影;避免 stock 誇張笑臉、避免俗豔 3D。

## 8. 聲音與語氣(Voice & Tone)

### 8.1 品牌人格(五個形容詞)

**嚴謹 · 可信 · 務實 · 克制 · 內行**(懂製造業與會計的行話,但不賣弄)。

### 8.2 語氣原則

- **Sober,不行銷腔、不裝可愛**;錯誤/系統訊息 sober 不浮誇。
- **講事實與可驗證的價值**(取代四套系統、補「算」的牆),不空喊「賦能/顛覆/革命」。
- **對製造業/會計用內行話**(傳票、過帳、批號、稼動率),但對操作員降術語(§8.4)。

### 8.3 用詞規範

- 一律「**Weyver(織雲)**」;**不**說 Ragic clone / 複製 / 類 Ragic。
- **繁體中文**為主,技術術語可保留英文;台灣在地用語(勞健保、統一發票、月結)。
- 產品標籤用**動詞 + 名詞、精簡**(「核准並過帳」「新增一列」),不用「立即體驗」「馬上開始」這類行銷句。

### 8.4 文案範例(Do / Don't)

| 情境 | ✅ Do(嚴謹務實) | ❌ Don't(SaaS 行銷腔) |
|---|---|---|
| 主行動按鈕 | 核准並過帳 · 儲存 · 匯出 Excel | 一鍵搞定 · 立即體驗 |
| 錯誤訊息 | 借貸不平衡:借 128,400 / 貸 128,000,差 400。請檢查明細。 | 哎呀!出了點小問題 😅 |
| 空狀態 | 尚無採購單。從上方「新增」建立第一筆,或匯入 Excel。 | 空空如也~快來新增吧! |
| 通知 | PO-0716-001 待你(採購主管)審核 · 07/22 交期 | 你有一則新消息! |
| 對外標題 | 一個平台,取代 Ragic + ERP + MES + ISO | 用 AI 顛覆你的企業管理 |
| 對外副標 | 你已在用 Ragic 取代 ERP,只是撞到「算」的牆 | 讓管理變得前所未有的簡單 |

### 8.5 繁中書寫規範(對內文件)

- 內部規劃文件(docs / CLAUDE / README / slide)採**企業級客觀書寫**:中性主詞(開發者 / 決策方 / 本規劃書)、**禁第一/二/三人稱代名詞、禁對話式主觀、禁戲劇字眼**。
- 不加特定人角色稱謂(用「拍板 / 裁定 / 決策」)。

- 官網 hero 為**行銷頁**,不受 `docs/14`「禁 in-app hero」限制,但仍**克制**:一句話定位 + 產品真截圖 + 明確 CTA(預約 demo);可用抽象格線背景(§7.2),**不俗豔**。
- 社群貼文:資料點 / 客戶場景 / 功能實screenshot;避免 meme 化。

### 9.6 白牌(White-label)

- 客戶可自訂:**主題色**(`--primary`,語意 token)+ **自家 logo**(取代 W 方塊)+ **自訂網域**(Caddy on-demand TLS,`docs/04 A`)。
- 白牌下**保留**:嚴謹結構規則(`docs/14`)、IBM Plex、狀態/信任訊號 —— 白牌換皮不換骨。

## 10. Do & Don't(品牌層)

| ✅ Do | ❌ Don't |
|---|---|
| 一律「Weyver(織雲)」;中文 day 1 主打 | 自稱 Ragic clone / 複製 / 類 Ragic |
| 品牌隱喻(織/雲)存於敘事與命名 | 把雲/織畫進產品介面當裝飾 |
| 產品內用嚴謹結構表達品牌 | 產品內加漸層 hero / pill / 陰影 |
| 三主題 = 一套系統的可切換配色 | 把三色講成三個品牌 / 隨意混色 |
| 對外用單一代表色維持識別 | 對外物料每次換不同主色 |
| IBM Plex 貫穿產品與物料 | 物料換字型(Inter / 系統預設) |
| Sober、務實、內行的文案 | 行銷腔、裝可愛、空喊顛覆 |
| 數字一律 Mono + tabular | 數字用比例字型不對齊 |
