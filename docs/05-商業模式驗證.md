---

## 0. TL;DR(值不值得?)

- **值得投入的三個支柱**|(1) **17 家 warm pipeline**(食品 / 團膳,已在導入既有產品,Weyver 為 next-gen 升級)—— 不是冷市場;(2) **高毛利**(OSS-only → 軟體授權 NT$0,毛利 ~80%);(3) **高價值定位**(一個平台取代 ERP+Ragic+MES+ISO 四套,ACV 可觀)。
- **關鍵風險**|ACV 若崩到 Ragic per-user 水準、pipeline 不轉換、solo 續航斷(docs/07 風險 3)。
- **解耦救時程**|docs/19 讓「可賣的 ERP subset」約 M18 就出,**營收不必等 solo 完整 MVP(務實 ~4-4.5 年 / 加速 ~3 年,docs/07 §1.4)** —— 這是回本模型的關鍵。
- **基準情境**|Y3 ARR ~NT$11M、Y5 ~NT$30M+;cash breakeven(solo)約 **Y2-3**。

## 1. 競品定價對照(定價錨點)

| 產品 | 模式 | 價格(估)| 涵蓋 |
|---|---|---|---|
| **Ragic** Enterprise | SaaS per-user | US$55/user/月,min 10 = **~NT$17.5K/月起**(僅表單)| 只有表單引擎那半 |
| **Odoo** | SaaS per-user + app | ~US$25-40/user/月 | ERP,但需自建 / 夥伴導入 |
| **SAP B1** | 永久授權 or 雲 | 永久 ~US$1.5-3K/user;雲 ~US$50-100/user/月 | ERP,導入費另計高 |
| **鼎新 / 正航**(台灣主流)| 永久授權 + 年維護 | 授權 ~NT$50 萬-數百萬 + 年維護 15-20% | ERP,MES/ISO/表單另購或無 |
| **Weyver** | **SaaS 訂閱** | 見 § 2 | **Ragic + ERP + MES + ISO 一站式** |

**定價邏輯**|客戶現況 = 鼎新/正航(NT$50 萬-數百萬 upfront + 年維護)**外加** Ragic(~NT$20 萬/年)**外加** MES / ISO 工具。Weyver **一份訂閱取代全部、無鉅額 upfront** —— 價值錨很高,可定在「取代四套系統」而非「per-user 表單」。

## 2. Weyver 定價模型(建議)

**Base 平台 + 模組訂閱 + 加購 user** 三段式(捕捉「一站式」價值,非純 per-user):

| 方案 | 月費(建議)| 年費 | 內容 |
|---|---|---|---|
| **基礎 Starter** | NT$10,000 | ~NT$120K | 表單引擎 + ERP core(GL/AP/AR/進銷)+ ≤10 users |
| **專業 Pro** | NT$28,000 | ~NT$336K | + 生產/MES + ISO + 品保 + ≤25 users |
| **企業 Enterprise** | NT$50,000+ | ~NT$600K+ | + 多廠區 + AI 加值 + 優先支援 + 不限 user |
| 加購 user | NT$600/user/月 | | 超出方案 seat |
| Onboarding(一次性)| NT$50-200K | | 資料遷移 + 導入 + 教育訓練 |

> **製造業客戶(食品廠)通常要 ERP+MES+ISO** → 落在 **Pro / Enterprise**,ACV ~NT$300-600K/年。

## 3. 客戶分層 + ACV 假設

| 客戶類型 | 方案 | ACV(保守 / 基準 / 樂觀)|
|---|---|---|
| 小型食品廠(<20 人)| Starter+ | NT$120K / 180K / 250K |
| **中型食品/團膳(20-50 人)← pipeline 主力** | Pro | **NT$250K / 400K / 550K** |
| 大型 / 集團多廠 | Enterprise | NT$600K / 900K / 1.5M |

**模型採「基準 ACV = NT$400K/年」**(pipeline 主力中型製造,取 ERP+MES+ISO)。

## 4. TAM 與 Pipeline

- **Warm pipeline**|**17 家**(食品 / 團膳,已導入既有產品,Weyver 為升級路徑)= 立即可轉換基礎。
- **近域 TAM**|台灣食品製造 SME 數千家;全製造業 SME **10 萬+ 家**。即使 1% 滲透 × NT$400K = 大市場。**TAM 不是限制,轉換 / 執行才是。**
- **擴散路徑**|17 pipeline → 食品 / 團膳同業口碑 → 泛製造 SME。

## 5. ARR 推估(5 年 · 3 情境)

**假設**|基準 ACV NT$400K;年流失 8%(ERP 黏著);客戶淨增如下。

| 年 | 客戶數(保守/基準/樂觀)| ARR 基準(NT$)|
|---|---|---|
| Y1(M18 後,ERP subset 可賣)| 3 / 4 / 6 | **~1.6M** |
| Y2 | 8 / 12 / 18 | **~4.8M** |
| Y3 | 18 / 28 / 42 | **~11.2M** |
| Y4 | 32 / 50 / 75 | **~20M** |
| Y5 | 50 / 80 / 120 | **~32M** |

> 樂觀情境 Y5 客戶 120 × 均 ACV 上修 → ARR 可達 NT$50-60M。保守情境 Y5 ~NT$20M。

## 6. 成本結構(OSS-only 高毛利)

| 成本項 | 水準 |
|---|---|
| **軟體授權** | **NT$0**(OSS-only,docs/11 §16)|
| **Infra**(VPS + Cloudflare)| 早期 ~NT$300-3K/月;規模化隨客戶 ~營收 5-8% |
| **LLM API**(AI 功能,docs/17)| 變動;~營收 3-5%,可 self-host OSS 模型壓低 |
| **開發**(主要成本)| solo 時間(機會成本 ~NT$1.5-2.5M/年)或團隊薪資 |
| **支援 / 導入** | per-customer;隨客戶數半變動 |

→ **SaaS on OSS = 高毛利(~75-85%)**;固定成本主要是開發(前期投入),變動成本低。**規模化後現金流結構極健康。**

---

## 7. 回本 / Breakeven

- **R&D 直接成本**|docs/07:solo 18 月 ~NT$800K-1.45M(不含開發者機會成本);含機會成本則每年 ~NT$1.5-2.5M。
- **解耦提早營收(docs/19 關鍵)**|「可賣的 ERP subset」約 **M18** 出 → 營收不必等 solo 完整 MVP(務實 ~4-4.5 年 / 加速 ~3 年)。Y1 就有 3-4 家 × NT$400K ≈ NT$1.6M。
- **Cash breakeven(solo)**|Y1 ARR ~1.6M vs 年成本 ~1-1.5M(含基本生活)→ **約 Y2-3 現金轉正**。
- **含機會成本的真回本**|若計開發者薪資機會成本,回本落 Y3-4(基準)—— 對一個能長成 NT$30M+ ARR、80% 毛利的 SaaS,合理。

## 8. 敏感度(關鍵槓桿)

| 槓桿 | 影響 |
|---|---|
| **ACV** | 最敏感。NT$400K→200K 直接砍半 ARR;守住「取代四套系統」定價是命脈 |
| **Pipeline 轉換率** | 17 家轉 3 vs 轉 10,Y1-2 差距大;warm 是最大資產 |
| **流失率** | ERP 黏著,8%→15% 會嚴重侵蝕複利 |
| **solo vs 團隊** | solo 慢但成本低;融資擴編快但攤薄 + 燒錢 |
| **完整 MVP 時程** | 解耦後不擋營收,但差異化(自建表 / AI)延後會影響擴散 |

---

## 9. 值不值得投入(誠實 verdict)

**值得,若下列成立**|
1. **Pipeline 轉換**|17 warm 轉 ≥3-5 家(門檻不高,已在用既有產品)。
2. **ACV 守住 ~NT$300K+**|定位在「取代四套系統」,不被殺到 per-user 表單價。
3. **解耦兌現**|docs/19 的 ERP subset 準時出,早營收。
4. **solo 續航或及時擴編 / 融資**|docs/07 風險 3(16-18hr/day 續航)是最大結構性風險。

**會殺死它的**|form-engine spike 失敗**且**解耦沒救到(docs/19 正是保險)、ACV 崩、流失高、開發者 burnout。

**上檔**|高毛利(OSS)+ 大 TAM(10 萬+ SME)+ 真 warm pipeline + 強差異化(Ragic 基底 + 計算層 + MES + ISO + AI)→ 可長成 NT$30-60M ARR 的高價值 SaaS,具融資 / 併購潛力。
