## 0. 定位與反面

**主畫面 = 表單記錄**(docs/24):使用者「自己建、自己填」的文件式表單 —— 分段、欄位對、子表,長得像客戶原本的紙本單據。ERP/MES/ISO 能力**織入**表單(GL 過帳、批號、簽核),非分立模組 tab。

**反面(一票否決)**|「普通 SaaS」語彙:大圓角、軟陰影、pill 徽章、飄浮卡片、大留白、in-app hero、裝飾動效、儀表板當首頁。凡出現即不合格。

### 0.1 v3「精緻資料工具」有據鬆綁(2026-07-20 裁定)

> **背景**|v2.1 純 austere(方角 2–3px / 全禁陰影)實作出來讀成「未上樣式的線框」。校正原則仍是 docs/11 §7.1 第一鐵則「**每個決策有 rationale,不用 vibe**」——**寫得出產品理由的才鬆,寫不出的維持禁**。toy-like 的真解 = 把嚴謹語言做出**工藝**(間距節奏、字階、對齊、真 Lucide icon、信任訊號),**非**加 Airtable 的裝飾。方向近 Bloomberg 終端高密度精品,非消費級 SaaS。

| 項目 | v2.1 | **v3 鬆綁到** | rationale(非 vibe)| 仍禁 |
|---|---|---|---|---|
| 圓角 | 2–3px | 容器/控件 **4–6px**(md=6 上限)| 純 2–3px 高密度下角落像沒畫完的線框;4–6px = 刻意描繪 | **pill / 全圓徽章**、>8px |
| 陰影 | 全禁 | **僅 overlay**(下拉/popover/modal/選單)極淡陰影(`--shadow-overlay`)| overlay 需與下層分層,hairline 分不出「浮於上」= **功能性 z 訊號** | resting 卡片/表格**仍禁陰影**(框線深度)|
| 漸層 | 禁 | **維持禁** | 無產品理由 | 品牌塊也平色 |
| 徽章/狀態 | 帶框方角章 | 維持帶框方角章(`StatusChip` = shadcn Badge outline);**+ 狀態層級**(見下)| pill 是消費裝飾;帶框章才是結構訊號 | pill;筆數/篩選也帶框非 pill;**裝飾圓點**(字已區分狀態,點=冗餘) |
| 密度 | 12.5px 緊 | **維持密度優先**;表格列高 ~34–38px;**4px 間距節奏** | 掃讀要密度;toy-like 靠節奏+字階非留白 | 46px 舒適大留白式 |
| 色彩 | 冷中性三主題+語意色 | **色只編碼語意**(狀態 / 型別族)| 色=訊號 | **裝飾性配色**(如彩色實體頭像)|
| Icon | Lucide 功能性 | 維持;**全面用真 Lucide 取代佔位字元** | §1.2 早允許;功能性辨識 | emoji / 裝飾 |
| 信任訊號 | 必備 | **強制**:時間戳到秒+人 / 版本 / 稽核 / 借貸平衡 / 狀態列 | 企業級「不像玩具」的本體語言 | — |

**token 對應**:`--radius-*` = 3/4/6/8;`--shadow-overlay`(僅 overlay);resting 一律 border。

**狀態層級(§0.1 資訊設計,非外觀 uplift)**|狀態非全等重:**要行動**者(待審 warn / 退回 error)留語意色;**已了結 / settled**(已核准 / 已收貨 / 完成)用 `neutral` 退到背景,**不用 ok 綠**——讓注意力導向該處理的,而非一片綠與待辦爭注意力(Linear/Height 範式)。極密次要表可再退為純文字+語意色(無框)。狀態靠**字 + 框 + 色**三者,**不加裝飾圓點**(字已完全區分、也已色盲友善,點對辨識零貢獻 = vibe)。

## 2. 設計 Token(v2 嚴謹)

> 權威值同步 `workspace-form-first-v2.html`;實裝於 `packages/ui/src/styles/tokens.css` @theme。**禁硬編 hex,一律語意 token。**

### 2.1 結構中性色

```css
--bg:#E8EAED;        /* 應用底 */         --card:#FFFFFF;    /* 面板 / 表單 */
--head:#F2F4F6;      /* 表頭 / 次底 */     --label:#EEF1F4;   /* 欄位 label 格底 */
--ink:#14181D; --ink-2:#3E4854; --ink-3:#6B7684; --ink-4:#98A2AE;
--line:#C9CFD6;      /* 面板框 */          --line-2:#DDE1E6;  /* 次分隔 */
--cell:#D5DAE0;      /* 欄位格線(全框線表)*/
```

### 2.2 主色與功能色(**v2.1 定案|一套系統、三配色主題可切換**)

**一套設計系統,`--primary` 家族語意化;三個官方配色主題以 `[data-theme]` 切換**(H 模組「表單主題 / 品牌客製」之基礎;預設深藍):

```css
:root, [data-theme="navy"] { --primary:#1E4E79; --primary-d:#173D5F; --primary-t:#E7EEF5; }  /* 深藍(預設)*/
[data-theme="teal"]        { --primary:#0C5F73; --primary-d:#094A5A; --primary-t:#E6F0F3; }  /* 深海青 */
[data-theme="graphite"]    { --primary:#313131; --primary-d:#1F1F1F; --primary-t:#ECECEA; }  /* 石墨 */

/* 跨主題不變(功能色,與主題解耦)*/
--link:#0B5CAB;                 /* 功能連結:藍 + underline */
--fx:#0B6B5D; --fx-bg:#E9F3F0;  /* 公式 / 計算結果 */
--rel:#5B3FA8;                  /* 關聯 Link&Load */
```

- `--primary` 用途限:分段條 / active tab / 主行動 / selected 指示。**結構中性色(§2.1)、狀態色(§2.3)、功能色跨主題共用** —— 保證三主題下嚴謹結構與可讀性一致。
- 元件**禁止**直接引用任一主題 hex;一律 `var(--primary*)`。
- 三主題白字對比皆過 AA(#1E4E79 / #0C5F73 / #313131 vs #FFF ≥ 7:1)。

### 2.3 狀態色(帶框章三值:字色 / 框色 / 底色)

```css
--ok:#1A7A43; --ok-line:#BFDCC9; --ok-t:#E8F2EB;    /* 已核准 / 合格 / 運行 */
--wn:#9A5B00; --wn-line:#E4CFA6; --wn-t:#F7EFDF;    /* 待審核 / 警示 */
--er:#B3261E; --er-line:#E7C4C1; --er-t:#F7E9E8;    /* 退回 / 異常 */
--nt:#4A5560; --nt-line:#CFD5DA; --nt-t:#ECEEF0;    /* 已收貨 / 中性 */
```

### 2.4 形狀與深度

- **圓角**|2–3px(輸入/按鈕/章);面板 0–3px。**禁 pill(9999px)、禁 >4px。**
- **陰影**|**禁用**。深度一律以框線(`--line` / `--cell`)表達。
- **間距**|4/8 節奏,**密度優先**(留白是手段不是風格)。

### 2.5 字級(資料密度基準)

| 角色 | 規格 |
|---|---|
| 頁/單據標題 H1 | 18 / 650 |
| 分段條標題 | 12 / 600(白字於 `--primary`)|
| 內文 / 欄位值 | 12.5 / 400 |
| 表格內容 | 12 / 400 |
| 欄位 label / 表頭 | 11.5 / 500 ·(表頭 10.5 / 600 uppercase 可)|
| 狀態章 / 輔助 | 10.5–11 / 500 |
| 數字 / 代碼 / 批號 / 時間戳 | IBM Plex Mono + `tnum`,同級字號 |

> **a11y 註**|資料密集畫面基準 12.5px(企業資料系統慣例);**閱讀型長文(說明/文件內文)仍 ≥14px**;對比一律 AA 4.5:1。

### 2.6 尺寸節奏(密度規範)

topbar 42px · 工具列 40px · 欄位列高 32px · 表格列高 ~28px · 按鈕/輸入高 26–28px · 狀態列 26px。

## 3. 結構與元件規則(v2 鐵則)

### 3.1 App 結構(對 docs/24)

```
┌──────────────────────────────────────────────────────┐
│ topbar 42px:品牌 + 客戶自建 app 頁籤(active=主色實底)│
│              + 全域搜尋 ⌘K + 租戶·使用者               │
├─────────┬────────────────────────────────────────────┤
│ 記錄 rail│ 工具列 40px:麵包屑 + 帶框按鈕(單一 primary)│
│ 228px   │           + 記錄導航「‹ 第 x / N 筆 ›」      │
│(表單/   ├────────────────────────────────────────────┤
│  列表    │ 表單記錄(文件式,max-w 880)                │
│  切換)  │  分段 × N + 子表 + 簽核 + 過帳 + 系統資訊    │
├─────────┴────────────────────────────────────────────┤
│ 狀態列 26px:連線·同步時間戳·租戶·權限·版本            │
└──────────────────────────────────────────────────────┘
```

- 導航 = **客戶自建之 app 頁籤**(採購/銷售/…),非系統模組 tab(docs/24 §2)。
- 多租戶:單一租戶固定顯示(topbar + 狀態列),**不放切換工作區 UI**。

### 3.2 表單記錄(主畫面)

- **分段條**|扁平主色實底、白字 12/600、方角、右側可帶說明(如「Link & Load 帶入供應商主檔」)。
- **全框線欄位表**|label 格(`--label` 底、右對齊、112px)+ 值格(白底),**每格四邊 `--cell` 框線**;雙欄分段並排;必填 `*`(紅)、欄位說明 `?` 圈;自動編號 / 帶入值以 `note` 註記。
- 單據抬頭:標題 + **Mono 單號** + 狀態章 + 右側「建立 / 最後更新」時間戳(到分)。

### 3.3 子表(line items)

列號欄(`#`,灰底 Mono)+ **直欄線**(全框)+ 數字右對齊 Mono + **合計列**(`--fx-bg` 底、2px 頂線、標明 `fx = Σ`)+「+ 新增一列」連結。

### 3.4 簽核 = 表格

欄:順序 / 簽核人 / 角色 / 結果(狀態章)/ **時間(Mono)** / 意見。不用頭像圓圈流程圖。

### 3.5 計算層呈現(織入的「算」)

GL 過帳 = **借貸表**:科目代碼(Mono)/ 科目 / 借方 / 貸方 + **「✓ 借貸平衡」斷言列** + 期間與鎖狀態(「期間 2026-07(未鎖)」)。估值 / 成本 / MRP 結果同理:**永遠顯示可驗證的計算依據**,不只顯示結果。

### 3.6 系統資訊與稽核(每記錄必備)

分段:建立(到秒 + 人)/ 最後更新(到秒 + 人)/ 版本 vN(歷史 / 還原連結)/ 稽核記錄入口。**時間戳是信任訊號,寧多勿少。**

### 3.7 狀態章

**帶框方形章**(2px 圓角):字色 + 框色 + 淡底三值(§2.3),文字必有(WCAG 雙編碼)。禁 pill。

### 3.8 工具列與記錄導航

帶框按鈕(26–28px 高、2px 圓角);**每畫面單一 primary**(主色實底,如「核准並過帳」);下拉以 `▾` 標示;**記錄導航「‹ 第 x / N 筆 ›」必備**(表單視圖)。

### 3.9 底部狀態列

連線狀態(dot + 文字)· 資料更新時間戳(Mono 到秒)· 租戶 · 權限摘要 · 產品版本(R1…)。

### 3.10 列表(次要視圖)

hairline 列分隔 + 表頭 `--head` 底;數字右對齊 Mono;**禁斑馬紋**;selected 列 = `--primary-t` 底 + 左 3px 主色 inset;密度 ~28px 列高。

### 3.11 連結

功能藍 `--link` + underline(offset 2px)。關聯值(Link&Load)用 `--rel` 可加虛線底。**禁無樣式「隱形連結」。**

### 3.12 MES 現場例外(S17)

平板/觸控密度反轉:目標 ≥44px、字級放大、疏朗;**token 與語言不變**(同一系統感);離線佇列狀態顯著。

### 3.13 空 / 載入 / 錯誤狀態

每 surface 皆設計;空狀態 = 說明 + 下一步動作(參 `workspace-hero.html` 地圖視圖範例);錯誤必含原因 + 復原路徑;載入 >300ms 用 skeleton(方角、無 shimmer 華麗感)。

### 3.14 a11y

AA 4.5:1;focus = 2px `--primary` outline(offset 1px),鍵盤全可達;狀態雙編碼;`prefers-reduced-motion` 尊重;表格語意化(`th` scope / `aria-sort`)。

### 3.15 動效(近乎無)

允許:hover/active 之 background/border 過渡 ≤120ms、panel 開合 ≤150ms。**禁**:入場動畫、stagger、parallax、彈跳、裝飾性 motion。資料變更以**時間戳更新**表達,不以動畫。

## 4. Do & Don't(v2)

| ✅ Do — 嚴謹企業級 | ❌ Don't — 普通 SaaS |
|---|---|
| 全框線欄位表、方角 2–3px、框線深度 | 大圓角、軟陰影、飄浮卡片 |
| 扁平主色分段條、active tab 實底 | 淡色 hero 分段、漸層 |
| 帶框方形狀態章 | pill 徽章 |
| 帶框工具列 + 單一 primary + 記錄導航 | ghost 按鈕群、多 primary |
| 時間戳到秒、版本、稽核入口、狀態列 | 無 system info 的「乾淨」畫面 |
| 科目代碼、借貸平衡斷言、列號、統編 | 只給結果不給依據 |
| 12.5px 密度、Mono tabular 數字 | 14px+ 大留白行銷排版 |
| 功能藍 underline 連結 | 隱形連結 |
| 表單記錄為主畫面(docs/24)| KPI 儀表板當首頁 |
| Lucide 功能性圖示、無 emoji | 彩色 icon 塊、emoji |
| 無動效(≤120ms 過渡)| 入場動畫 / stagger / 裝飾動效 |
| 一個 Ragic 工作區、能力織入 | 每系統一個模組 tab |

> **迭代紀錄**|v1 經 6 版首頁迭代定「軟企業 SaaS」(深海青/圓角/陰影)→ 2026-07-19 經 docs/24 心智模型校準(form-first、Ragic 範式)+ 用戶指正「太像普通 SaaS,無 Ragic/ERP/MES/ISO 嚴謹感」→ **v2 嚴謹企業級定案**(全框線/方角/扁平分段條/密度/信任訊號)。教訓:企業級的信任感來自**嚴謹的結構訊號**(框線、代碼、時間戳、平衡斷言),不是品牌色與留白。
